## 開倉 / 平倉 / 建倉（Open / Close Position） {#開倉平倉}

| 項目 | 說明 |
|------|------|
| **英文** | Open position (建倉) / Close position |
| **定義** | 開倉（建倉）：開始建立一筆交易部位，可做多（買進）或做空（融券賣出）；平倉：結束該筆部位的反向操作（賣出多單、買回平空單）；加碼／減碼：在已有部位上增加或減少數量 |
| **在哪裡看到** | 交易軟體「下單」「平倉」按鈕、投資社群「我昨天開倉」 |
| **常見誤解** | 開倉 = 一定要賺；開倉只是開始，風控與停損同樣重要 |
| **小例子** | 先開倉買 1 張，回檔加碼 1 張，達目標分批平倉 |

相關：[持倉與交易](position.md) · [交易流程](../01-basics/trading-flow.md)

## 抄底（Bottom Fishing） {#抄底}

| 項目 | 說明 |
|------|------|
| **英文** | Bottom fishing |
| **定義** | 在股價跌至認為的「極低」或恐慌區間時買進，期待日後回升獲利；屬於**逆勢**操作 |
| **在哪裡看到** | 急跌後的社群討論、新聞「低接買盤」 |
| **常見誤解** | 跌很多就便宜；可能只是「從貴變合理」，甚至「從合理變更便宜」 |
| **小例子** | 股價腰斬後進場，但下跌趨勢未止 → 越接越深 |

!!! warning "新手提醒"
    口袋小學堂等影片多建議新手勿輕易抄底；若要做，需有明確支撐、基本面與 [停損](../06-risk/stop-loss.md) 計畫。用指標分辨「止跌」還是「弱勢反彈」見 [手冊：接盤還是追高](../04-charts/catch-or-chase.md)、[案例：弱勢反彈](../07-cases/weak-rebound-trap.md)。

## 接盤 / 接刀（Catching a Falling Knife） {#接盤}

| 項目 | 說明 |
|------|------|
| **英文** | Catching a falling knife |
| **定義** | 股價仍在下跌趨勢（或急跌未止）時進場低接，結果買在半山腰、持續承壓；口語常與「接刀」混用，接近逆勢 [抄底](#抄底) 失敗的情況 |
| **在哪裡看到** | 社群「又去接盤」、下跌中的反彈討論 |
| **常見誤解** | 跌深就會反彈讓你解套；可能越接越深 |
| **小例子** | MACD 零軸下金叉就重倉 → 反彈失敗續跌 |

完整判讀：[手冊：接盤還是追高](../04-charts/catch-or-chase.md)；練習：[案例：弱勢反彈接盤](../07-cases/weak-rebound-trap.md)。對照「不是接盤」：[案例：健康回檔](../07-cases/healthy-pullback.md)。

## 追高殺低（Chasing Highs, Selling Lows） {#追高殺低}

| 項目 | 說明 |
|------|------|
| **英文** | Chasing highs, selling lows |
| **定義** | 追高：股價已大幅上漲、情緒火熱時才買進；殺低：股價急跌、恐慌時在相對低點賣出；合稱高買低賣，是常見虧損原因 |
| **在哪裡看到** | 情緒交易後的對帳單、社群「又買在高點」 |
| **常見誤解** | 跟著熱度走就安全；貪婪與恐懼正是追高殺低的根源 |
| **小例子** | 利多噴出追在漲停 → 隔日回檔恐慌殺在低點 |

**改善方向**：[分批](#分批) 進出、[紀律](../06-risk/discipline.md)、事先寫好進出場計畫。圖表判讀：[手冊：接盤還是追高](../04-charts/catch-or-chase.md)；定義：[定義：假突破](technical.md#假突破)；案例：[案例：缺口假突破](../07-cases/gap-breakout.md)、[案例：追高陷阱](../07-cases/chase-high-trap.md)、[案例：MACD 頂背離](../07-cases/macd-divergence.md)。

## 回檔 / 拉回（Pullback） {#回檔}

| 項目 | 說明 |
|------|------|
| **英文** | Pullback |
| **定義** | 股價在**上漲趨勢**過程中，出現暫時性下跌 |
| **在哪裡看到** | 上升趨勢中的短期黑K、跌向均線 |
| **常見誤解** | 回檔 = 轉空；在強勢股中，健康回檔是常態 |
| **小例子** | 拉回不破 MA20 → 趨勢可能延續；拉回很深 → 留意趨勢轉弱 |

健康回檔與接盤的對照演練：[案例：健康回檔](../07-cases/healthy-pullback.md)、[手冊情境 3](../04-charts/catch-or-chase.md)。

## 反彈（Rebound） {#反彈}

| 項目 | 說明 |
|------|------|
| **英文** | Rebound |
| **定義** | 股價在**下跌趨勢**過程中，出現暫時性回升（像球落地彈起） |
| **在哪裡看到** | 下跌趨勢中的短期紅K、回升至均線附近 |
| **常見誤解** | 反彈 = 落底回升；反彈不過均線或前高常是弱勢訊號 |
| **小例子** | 反彈不過 MA20 又下跌 → 空頭可能仍占優 |

回檔與反彈都是**波動中的正常現象**，關鍵在趨勢方向與位置。見 [行情與報價](quotes.md)、[均線](../04-charts/ma.md)、[手冊：接盤還是追高](../04-charts/catch-or-chase.md)。

## 套牢 / 解套（Locked-in / Break-even Recovery） {#套牢解套}

| 項目 | 說明 |
|------|------|
| **英文** | Locked-in (underwater) / Break-even recovery |
| **定義** | 套牢：買進後股價低於成本，不願認賠而繼續持有，資金被占用；解套：股價回升至成本價或以上，可賣出不虧損 |
| **在哪裡看到** | 投資社群「我套了 20%」、新聞「套牢賣壓」 |
| **常見誤解** | 只要不賣就不算虧；帳面虧損與機會成本都是真實的 |
| **小例子** | 100 買進跌到 80（套牢），回到 100 才解套 |

**與打底的關係**：股價在底部區間反覆震盪時，早期買進者常形成套牢賣壓，見 [市場進階術語](market-terms.md#打底)。

## 分批（Scaling） {#分批}

| 項目 | 說明 |
|------|------|
| **英文** | Scaling (in tranches) |
| **定義** | 分批加碼（買）：不一次 All in，分數次買進以降低買在尖點的風險；分批停利（賣）：漲一段先賣一部分，其餘續抱以鎖定部分獲利 |
| **在哪裡看到** | 交易計畫、資金配置規則 |
| **常見誤解** | 分批等於攤平；攤平是虧損加碼，分批是事先規劃的進出節奏 |
| **小例子** | 計畫買 3 張 → 先 1 張試單，回檔再加 1 張，突破確認後加最後 1 張 |

相關：[資金配置](../06-risk/capital.md) · [停損停利](../06-risk/stop-loss.md)

## 攤平（Averaging Down） {#攤平}

| 項目 | 說明 |
|------|------|
| **英文** | Averaging down |
| **定義** | 虧損後再買進同標的以拉低平均成本；與事先規劃的 [分批](#分批) 不同，常是論點失效後的情緒加碼 |
| **在哪裡看到** | 「先攤一下成本」、套牢後加碼 |
| **常見誤解** | 攤平等於分批布局；下跌趨勢攤平＝加大接盤 |
| **小例子** | 情境 1 接盤後再攤 → 虧損與曝險同時放大 |

相關：[接盤](#接盤) · [曝險](risk.md#曝險) · [紀律](../06-risk/discipline.md)。

## 半山腰（Halfway Entry） {#半山腰}

| 項目 | 說明 |
|------|------|
| **英文** | Buying halfway / mid-trend catch |
| **定義** | 以為到底或到頂而進場，實際只買在中段；下跌中的半山腰＝接盤，上漲中的半山腰也可能變成追高末段 |
| **在哪裡看到** | 複盤時「買在波段中間」 |
| **常見誤解** | 已經跌一半就安全；趨勢可遠長於預期 |
| **小例子** | 零軸下金叉進場後續跌 → 典型半山腰接盤 |

案例：[案例：弱勢反彈](../07-cases/weak-rebound-trap.md)。

## FOMO（害怕錯過） {#fomo}

| 項目 | 說明 |
|------|------|
| **英文** | Fear Of Missing Out |
| **定義** | 因害怕錯過上漲而衝動追價；是 [追高](#追高殺低) 的常見心理驅動 |
| **在哪裡看到** | 社群「不追會後悔」、熱門股討論串 |
| **常見誤解** | 熱度＝機會；熱度常是風險標籤 |
| **小例子** | 量縮創高仍市價追進 → FOMO 追高 |

相關：[FOMO 族](../10-persona/active.md#⑧-fomo-追風族) · [追高陷阱](../07-cases/chase-high-trap.md)。

## 類股（Sector） {#類股}

| 項目 | 說明 |
|------|------|
| **英文** | Sector |
| **定義** | 依**產業**分類的股票群體（電子／半導體、金融、航運、鋼鐵等） |
| **在哪裡看到** | 產業漲跌幅排行、「今天電子強、傳產弱」 |
| **常見誤解** | 同類股齊漲齊跌；龍頭與二三線分化常見 |
| **小例子** | 比較同類股 PER → 判斷個股相對貴或便宜 |

相關：[跨市場與產業](../05-analysis/cross-market.md) · [基本面框架](../05-analysis/fundamental-framework.md#行業層次)

## 「回測」兩種意思（Backtest / Retest） {#回測}

| 項目 | 說明 |
|------|------|
| **英文** | Backtest（策略） / Retest（支撐壓力） |
| **定義** | 策略回測：把交易策略套用到**歷史資料**檢驗過去績效（量化、程式交易）；技術回測：價格**回頭測試**支撐線或壓力線（K 線、技術分析） |
| **在哪裡看到** | 量化報告、技術分析畫線 |
| **常見誤解** | 兩種「回測」混用；閱讀時請依上下文判斷 |
| **小例子** | 回測不破支撐 → 支撐有效；跌破支撐 → 該價位常轉為壓力 |

詳見 [技術面術語](technical.md#回測支撐) · [策略回測](../appendix/video-resources.md#口袋小學堂-ep53)

## 自我檢查

??? question "1.（概念題）回檔與反彈各發生在什麼趨勢中？接盤比較像哪一種？"
    參考答案：**回檔**在漲勢中、**反彈**在跌勢中；**接盤**常發生在把空頭反彈誤當落底。見 [接盤](#接盤)。

??? question "2.（判斷題）分批與攤平是同一件事？"
    參考答案：否。**分批**是事先規劃；**攤平**常是虧損後情緒加碼，下跌中等於加大接盤。見 [攤平](#攤平)。

??? question "3.（情境題）社群喊「不追會後悔」時，這比較像哪個詞？該怎麼標情境？"
    參考答案：**FOMO**；圖表上若量縮創高／頂背離，標追高風險。見 [FOMO](#fomo)、[追高陷阱](../07-cases/chase-high-trap.md)。

## 重點回顧

- **開倉／平倉**是部位生命週期的起迄；**追高殺低**、**接盤**、**攤平**、**FOMO** 是常見虧損組合。
- **回檔**發生在漲勢中，**反彈**發生在跌勢中；不要把兩者都叫「低接」。
- **分批**可控制貪恐；**攤平**不是分批。
- **回測**一字兩義：策略驗證 vs 價格測試支撐。
