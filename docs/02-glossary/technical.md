# 技術面術語

## 本篇你會學到

- 均線、MACD、RSI、KD、布林與**零軸／背離／乖離／突破／盤整**等進場相關詞
- 各指標適合回答什麼問題；如何接到 [接盤還是追高](../04-charts/catch-or-chase.md)

K 線是技術面的基礎，建議先讀 [K 線基礎](../04-charts/kline-basics.md)、[三招讀懂 K 線](../04-charts/kline-reading.md)、[16 種型態](../04-charts/candle-patterns.md)。

## 均線（MA） {#均線-ma}

| 項目 | 說明 |
|------|------|
| **英文** | Moving Average (MA) |
| **定義** | 過去 N 日收盤價的平均值，如 MA5、MA20、MA60 |
| **在哪裡看到** | K 線圖上的曲線 |
| **常見誤解** | 均線是未來價格；它是**滯後**的趨勢描述 |
| **小例子** | 收盤站上 MA20 → 短期趨勢偏多（但不保證續漲） |

詳見 [均線教學](../04-charts/ma.md)。

---

## MACD {#macd}

| 項目 | 說明 |
|------|------|
| **英文** | MACD (Moving Average Convergence Divergence) |
| **定義** | 由快線、慢線指數移動平均及其差離（DIF）與訊號線（Signal）組成的趨勢動能指標 |
| **在哪裡看到** | K 線圖下方副圖 |
| **常見誤解** | 金叉必買；盤整時假訊號多 |
| **小例子** | DIF 上穿訊號線（黃金交叉）→ 動能轉強參考 |

詳見 [MACD 教學](../04-charts/macd.md)。用零軸與背離分辨接盤／追高見 [接盤還是追高](../04-charts/catch-or-chase.md)。

---

## RSI {#rsi}

| 項目 | 說明 |
|------|------|
| **英文** | RSI (Relative Strength Index) |
| **定義** | 相對強弱指標，0–100，常見 14 日；>70 視為超買區、<30 視為超賣區 |
| **在哪裡看到** | 副圖 RSI 曲線 |
| **常見誤解** | 超買一定跌；強勢股可長期停留在高位 |
| **小例子** | RSI 由 30 以下回升 → 短線轉強參考 |

詳見 [RSI 教學](../04-charts/rsi.md)。

---

## KD {#kd}

| 項目 | 說明 |
|------|------|
| **英文** | KD (Stochastic Oscillator) |
| **定義** | 隨機指標，比較收盤價在近期高低區間的位置；K 線與 D 線交叉為常見訊號 |
| **在哪裡看到** | 副圖 KD |
| **常見誤解** | K 在 80 以上只能賣；需搭配趨勢與成交量 |
| **小例子** | 低檔 K 上穿 D（黃金交叉）→ 短線轉強參考 |

詳見 [KD 教學](../04-charts/kd.md)。

---

## 布林通道（Bollinger Bands） {#布林通道}

| 項目 | 說明 |
|------|------|
| **英文** | Bollinger Bands |
| **定義** | 以移動平均為中軌，上下軌為 ±N 倍標準差，股價常在通道內波動 |
| **在哪裡看到** | K 線圖包覆通道 |
| **常見誤解** | 觸下軌必買；趨勢下跌時可能沿下軌行走 |
| **小例子** | 開口收窄後突然放大 → 波動率上升的參考 |

詳見 [布林通道教學](../04-charts/bollinger.md)。

---

## 超買 / 超賣（Overbought / Oversold） {#超買超賣}

| 項目 | 說明 |
|------|------|
| **英文** | Overbought / Oversold |
| **定義** | 市場因消息或情緒，出現**過度買進**（超買）或**過度賣出**（超賣）的狀態 |
| **在哪裡看到** | RSI、KD 進入高位或低位區間 |
| **常見誤解** | 超買一定跌；強勢股可長期超買，需搭配趨勢與 [回檔](trading-terms.md#回檔) 判斷 |
| **小例子** | 利空恐慌後 RSI < 30 → 超賣，留意反彈但非保證落底 |

| 面向 | 說明 |
|------|------|
| **情緒面** | 利多狂歡、利空恐慌，常見於新聞事件後 |
| **指標面** | RSI、KD 進入高位或低位區間 |

參考：[RSI](#rsi) · [口袋 EP53](../appendix/video-resources.md#口袋小學堂-ep53)

## 支撐 / 壓力（Support / Resistance） {#支撐--壓力}

| 項目 | 說明 |
|------|------|
| **英文** | Support / Resistance |
| **定義** | 歷史上股價多次反彈的價位（支撐）或受阻回落的價位（壓力） |
| **在哪裡看到** | K 線畫線、前高前低、整數關卡 |
| **常見誤解** | 支撐永不破；放量跌破支撐可能轉為壓力（支撐變壓力，像天花板） |
| **小例子** | 多次在 100 附近止跌 → 100 為支撐；跌破後 100 常變壓力 |

---

## 回測（支撐）（Retest） {#回測支撐}

| 項目 | 說明 |
|------|------|
| **英文** | Retest (support / resistance) |
| **定義** | 價格回落或反彈後，**回頭測試**某一條支撐線或壓力線 |
| **在哪裡看到** | 突破後拉回測試頸線、均線回測 |
| **常見誤解** | 與策略回測混淆；此處指價格測試支撐壓力 |
| **小例子** | 回測不破支撐 → 支撐有效；跌破支撐 → 該價位常轉為壓力 |

!!! note "一字兩義"
    「回測」亦指把交易策略套用到歷史資料，見 [交易行為術語](trading-terms.md#回測)。

參考：[學吧十大名詞](../appendix/video-resources.md#學吧-learningpa-十大名詞)

## 頭肩頂（Head and Shoulders） {#頭肩頂}

| 項目 | 說明 |
|------|------|
| **英文** | Head and shoulders |
| **定義** | 常見的**反轉型態**：走勢形成左肩、頭部（最高點）、右肩，底部連線為**頸線** |
| **在哪裡看到** | 日線、週線高檔的三峰結構 |
| **常見誤解** | 形狀像就是頭肩頂；盤整中類似形狀可能只是噪音 |
| **小例子** | 頸線放量跌破 → 常被視為趨勢轉空訊號（需搭配量） |

相關：[K 線組合型態](../04-charts/candle-combinations.md) · [16 種型態](../04-charts/candle-patterns.md)

## 型態（Chart Pattern） {#型態}

| 項目 | 說明 |
|------|------|
| **英文** | Chart pattern |
| **定義** | 價格走勢在圖上形成的**形狀**（如頭肩頂、雙底、三角形） |
| **在哪裡看到** | K 線整體結構、趨勢線之間 |
| **常見誤解** | 型態一定兌現；型態突破才是關鍵，且需量能配合 |
| **小例子** | 型態不破 → 趨勢可能延續；型態突破 → 可能開啟新方向 |

**學員建議**：先熟練少數實用型態（單根 [16 種](../04-charts/candle-patterns.md)、[組合](../04-charts/candle-combinations.md)），再擴充。

## 黃金交叉 / 死亡交叉（Golden / Death Cross） {#黃金交叉}

| 項目 | 說明 |
|------|------|
| **英文** | Golden cross / Death cross |
| **定義** | 黃金交叉：短期均線向上穿越長期均線；死亡交叉：短期均線向下穿越長期均線。MACD 的 DIF 上穿／下穿 Signal 也常口語稱金叉／死叉 |
| **在哪裡看到** | 均線組合、MACD 快慢線 |
| **常見誤解** | 交叉就是買賣訊號；盤整時假訊號多，且**零軸上下**意義不同 |
| **小例子** | MA5 上穿 MA20 → 黃金交叉；MACD 零軸下金叉 → 常是弱勢反彈（見 [接盤還是追高](../04-charts/catch-or-chase.md)） |

相關：[均線](../04-charts/ma.md) · [MACD](../04-charts/macd.md)

## DIF / Signal / MACD 柱 {#dif-signal}

| 項目 | 說明 |
|------|------|
| **英文** | DIF / Signal (DEA) / MACD histogram |
| **定義** | DIF＝EMA(12)−EMA(26)；Signal＝DIF 的 EMA(9)；柱＝DIF−Signal，反映兩線差距 |
| **在哪裡看到** | K 線副圖 MACD |
| **常見誤解** | 只看交叉當日；交叉後柱是否**連續擴大**更重要 |
| **小例子** | 金叉後柱立刻縮回 → 動能不足，訊號含金量低 |

詳見 [MACD](../04-charts/macd.md)。

## 零軸（MACD Zero Line） {#零軸}

| 項目 | 說明 |
|------|------|
| **英文** | MACD zero line / zero axis |
| **定義** | MACD 圖上 DIF＝0 的水平線；DIF 在零軸上偏多環境，在零軸下偏空環境 |
| **在哪裡看到** | MACD 副圖中央虛線／實線 |
| **常見誤解** | 零軸下金叉＝大反轉；多數是弱勢反彈 |
| **小例子** | 同樣金叉：零軸上較像回檔結束；零軸下較像接盤風險 |

詳見 [接盤還是追高](../04-charts/catch-or-chase.md) · [MACD](../04-charts/macd.md#接盤還是追高)。

## 動能背離（頂背離／底背離） {#動能背離}

| 項目 | 說明 |
|------|------|
| **英文** | Momentum divergence (bearish / bullish) |
| **定義** | 頂背離：股價新高但 MACD／RSI 未新高；底背離：股價新低但指標未新低。代表動能與價格不同步 |
| **在哪裡看到** | 日 K 高點／低點對照副圖 |
| **常見誤解** | 背離＝立刻反轉下單；僅為警訊，常先橫盤 |
| **小例子** | 價 100→105 新高，DIF 反而下滑 → 頂背離，追高風險升 |

案例：[MACD 頂背離](../07-cases/macd-divergence.md) · [追高陷阱](../07-cases/chase-high-trap.md)。與 [量價背離](market-terms.md#量價背離) 不同（一個比指標，一個比成交量）。

## 鈍化（Indicator Failure Swing / Flatlining） {#鈍化}

| 項目 | 說明 |
|------|------|
| **英文** | Indicator persistence in extreme zone（俗稱鈍化） |
| **定義** | RSI／KD 長期黏在超買或超賣區，交叉訊號反覆出現卻不立即反轉 |
| **在哪裡看到** | 強勢股 RSI>70 很久；弱勢股 RSI<30 很久 |
| **常見誤解** | 超買就一定跌、超賣就一定漲 |
| **小例子** | 多頭中 KD 高檔鈍化 → 可能續漲；空頭低檔鈍化 → 勿急抄底 |

相關：[RSI](../04-charts/rsi.md) · [KD](../04-charts/kd.md)。

## 乖離率（Bias / Deviation from MA） {#乖離率}

| 項目 | 說明 |
|------|------|
| **英文** | Bias ratio / deviation from moving average |
| **定義** | 現價相對某條均線偏離的幅度；乖離過大常意味短線過熱或過冷 |
| **在哪裡看到** | 看盤軟體「乖離」、或以 (收盤−MA)/MA 估算 |
| **常見誤解** | 乖離大就一定回歸；強勢趨勢可維持偏大乖離一段時間 |
| **小例子** | 股價遠高於 MA20 且量縮創高 → 追高風險參考 |

相關：[均線](../04-charts/ma.md) · [追高陷阱](../07-cases/chase-high-trap.md)。

## 突破（Breakout） {#突破}

| 項目 | 說明 |
|------|------|
| **英文** | Breakout |
| **定義** | 價格有效穿越整理區上緣、前高或關鍵均線／頸線，並常伴隨量增 |
| **在哪裡看到** | 日 K 穿過壓力、跳空缺口 |
| **常見誤解** | 穿越當下就追；需看量與是否站穩 |
| **小例子** | 放量站上整理上緣並連收兩日站穩 → 突破延續候選 |

對照假突破見下節；框架：[接盤還是追高情境 5／6](../04-charts/catch-or-chase.md)；案例：[突破站穩](../07-cases/breakout-hold.md)。

## 假突破（False Breakout / Fakeout） {#假突破}

| 項目 | 說明 |
|------|------|
| **英文** | False breakout / fakeout |
| **定義** | 價格短暫穿越關鍵支撐／壓力後無法站穩，迅速回到整理區內 |
| **在哪裡看到** | 跳空後回補、量縮刺穿前高 |
| **常見誤解** | 一旦穿越就必續漲；無量、不站穩常失敗 |
| **小例子** | D0 跳空突破、D+2 跌回箱內 → 假突破，宜執行無效點 |

案例：[突破缺口與假突破](../07-cases/gap-breakout.md)。真突破對照：[突破站穩](../07-cases/breakout-hold.md)。

## 盤整（Consolidation / Range） {#盤整}

| 項目 | 說明 |
|------|------|
| **英文** | Consolidation / trading range |
| **定義** | 價格在區間內來回、均線糾纏，趨勢不明顯 |
| **在哪裡看到** | 日 K 箱型、布林收口 |
| **常見誤解** | 盤整時金叉死叉仍很準；其實假訊號多，宜降指標權重 |
| **小例子** | MA5／MA20 糾纏＋MACD 柱在零軸上下抖 → 觀望或縮小週期外的意義 |

相關：[布林](../04-charts/bollinger.md) · [多週期](../09-advanced/multi-timeframe.md)。

## 自我檢查

??? question "1.（概念題）技術指標為何要標示滯後性？"
    參考答案：指標由**過去價格**計算，反應慢於當下；強勢股可能超買續漲。

??? question "2.（判斷題）出現黃金交叉就應立即買進？"
    參考答案：否。盤整時假訊號多，需搭配**趨勢、零軸與位置**；見 [零軸](#零軸)。

??? question "3.（情境題）RSI 與 MACD 各偏回答什麼？頂背離常對到哪種進場風險？"
    參考答案：RSI 偏**震盪冷熱**；MACD 偏**趨勢動能**；頂背離常對 **追高風險**，見 [動能背離](#動能背離)。

## 重點回顧

- 技術面描述**價格與量能的行為**，不直接告訴你公司好不好。
- 指標互相驗證優於單一訊號；**金叉先問零軸，創高先問背離**。
- 型態與指標需搭配**位置**（高檔 / 低檔 / 趨勢中 / 盤整）。
